# Free source review — Phuket property project

No checked free source established 500 active Phuket sale/rent listings with commercial republication rights. Import authorized owner/broker inventory with actual evidence; map and government assessment records cannot become offers.

| Source | Actual useful data | Limit |
| --- | --- | --- |
| [OpenStreetMap](https://www.openstreetmap.org/copyright) | Places, roads, buildings; ODbL | No asking prices, ownership permission or property photos |
| [Wikidata](https://www.wikidata.org/wiki/Wikidata:Licensing) | CC0 structured places | No active inventory or image rights |
| Wikimedia Commons | Destination photos with individual licenses | Per-image compliance; never relabel as actual property photos |
| [Treasury land valuation](https://catalog.treasury.go.th/dataset/land-valuation) | 215944 Phuket assessment rows from anonymous API | Assessment is not asking price; exact license unresolved from “Open Data Common” label |
| [Treasury condo valuation](https://catalog.treasury.go.th/dataset/condominium-valuation) | 4707 Phuket assessment rows | No availability, asking price, coordinates or photo permission |
| [DOL parcels](https://data.go.th/dataset/mapland-parcel) | Parcel data | Written permission and issued consumer credentials; not an anonymous listing feed |
| Legal Execution Department aggregates | Auction statistics | Noncommercial license unsuitable for this commercial catalog; not inventory |

The existing licensed Phuket POI extract has 1868 records. Retain OSM attribution and ODbL access/share-alike obligations; keep the derived database separate from proprietary property inventory. POIs do not count toward the contracted 500 properties.

Frankfurter v2 supplies 30 THB quote currencies from the ECB-specific endpoint without a key. Keep the source/as-of date; this is a conversion reference, not property prices. See [Frankfurter](https://frankfurter.dev) and [ECB terms](https://www.ecb.europa.eu/services/disclaimer/html/index.en.html).

Public Nominatim permits at most one request per second and prohibits autocomplete/systematic extraction. Community tiles have no production SLA and prohibit bulk downloading. Geoapify offers a free commercial tier requiring registration, key and attribution; none is configured.

Findings describe checked sources, not every possible future supplier. Actual inventory, image/coordinate publication permission and user acceptance remain required.
